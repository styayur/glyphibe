# Glyphibe

Graph-first code comprehension: explore real code relationships and learn
programming concepts through traceable, local analysis.

**Development status:** implementation and verification are in progress.
There is no stable release or installable product yet. Do not treat this
repository as Glyphibe v1.0.0 Stable.

The planned core works offline without a language model or API key. Python,
Rust, JavaScript and TypeScript/TSX are the priority languages. Feature claims
will be added only after implementation and verification.

See the [release gate ledger](docs/development/release-gates.md),
[implementation contract](docs/development/implementation-contract.md), and
[license decision](docs/adr/0001-license-and-clean-implementation.md).
