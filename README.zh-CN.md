# Glyphibe

以图谱为中心的代码理解工具：通过可追溯的本地分析探索真实代码关系，
并循序学习编程概念。

**开发状态：** 正在实现和验证。目前没有稳定版本或可安装的成品。
请勿将本仓库视为 Glyphibe v1.0.0 Stable。

计划中的核心可离线运行，无须语言模型或 API Key。优先支持 Python、
Rust、JavaScript 和 TypeScript/TSX。功能声明将在实现并验证后补充。

参见[发布门禁](docs/development/release-gates.md)、
[接口约定](docs/development/implementation-contract.md)及
[许可证决策](docs/adr/0001-license-and-clean-implementation.md)。

原创代码采用 MPL-2.0。依赖保留各自的许可证。
