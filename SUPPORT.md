# Support

Use GitHub issues for reproducible defects and Discussions for usage questions.
Include Glyphibe version, operating system, language and a minimal public
example. Remove private source and local paths from logs or screenshots.

For incorrect edges, include the relation's evidence kind/method and the
expected target. Unresolved dynamic calls are an explicit limitation; suggest
a safe, reproducible resolution rule if one is known. Use private vulnerability
reporting for security problems.

There is no paid support commitment or guaranteed response time. Development
builds are not stable releases. Installation instructions and platform claims
must be read together with the release's verification notes.
